# Elegant Premium Website Redesign & Brand Architecture
**Brand Concept**: VANGUARD ATELIER  
**Aesthetic Profile**: Modern, Polished, Luxury Editorial Digital Experience  
**Tech Stack**: HTML5, CSS3 Custom Properties, Vanilla ES6+ JavaScript, Modular PHP  

---

## 🚀 Quick Start / How to View

### 1. Direct Browser Preview (Instant Standalone)
Simply double-click or open any of the following HTML files in Google Chrome, Edge, Safari, or Firefox:
- **`index.html`** &mdash; Main Interactive Flagship Experience (Includes Hero, Device Simulator, Before/After Slider, Services, Portfolio, Handover Tabs, and Multi-Step Booking Wizard)
- **`about.html`** &mdash; Heritage, Brand Story, Leadership & Evolution Timeline
- **`services.html`** &mdash; Capabilities, Package Comparison Table, and Deliverables Matrix
- **`portfolio.html`** &mdash; Curated Case Studies with interactive modal details
- **`design-system.html`** &mdash; Standalone Interactive Design System & UI Tokens
- **`contact.html`** &mdash; Confidential Consultation & Booking Wizard

### 2. PHP Server Execution (Optional)
If running in a PHP environment (e.g. Apache, Nginx, XAMPP, or built-in PHP CLI):
```powershell
php -S localhost:8000
```
Then visit `http://localhost:8000` to preview the modular PHP architecture (`index.php`, `includes/header.php`, `includes/navigation.php`, `includes/footer.php`).

## 💎 Features Implemented Against Client Requirements

| Client Requirement | Implementation in This Project |
| :--- | :--- |
| **Modern, polished, premium aesthetic** | Obsidian & Brushed Champagne Gold palette, glassmorphism, subtle glowing auras, and refined typography. |
| **Refined Typography** | Editorial serif display fonts (`Cormorant Garamond`, `Cinzel`) paired with geometric sans (`Plus Jakarta Sans`). |
| **Cohesive Colour Palette** | Tokenized CSS variables with live Dark/Light theme switcher. |
| **Elegant Spacing** | Strict 8-point spatial baseline ensuring breathing room and visual calm. |
| **Smooth Micro-interactions** | Touch-friendly Before/After split slider, card hover elevations, smooth scrolling, and toast notifications. |
| **Fully Responsive Layouts** | Tested for Desktop (1440px), Tablet (768px), and Mobile (390px) with interactive simulator bar. |
| **Organised Design System** | Interactive design system with 1-click clipboard copy for all hex codes. |
| **Concise Handover Guide** | Fully documented in `DESIGN_HANDOVER_GUIDE.md` and `design-system.html`. |
